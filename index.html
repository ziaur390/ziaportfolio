Published 2025

Decoupled IoT Architecture for Coal Mine Safety

The Sciencetech, Qurtuba University · Vol. 6, No. 4, pp. 187–205 · M. Salman, I. U. Haq, Z. U. Rahman

Co-authored a modular IoT safety architecture for subterranean coal mines with no dependency on pre-built underground networking: sensor units measuring gas, flame, temperature and humidity; miner smart jackets issuing SOS alerts; and a cloud-synchronised control unit. Published results include end-to-end alert latency under 350 ms, 98% of alerts delivered in under 250 ms, and a wireless range of 112 ± 5 m line-of-sight.

Message-Driven Infrastructure

Event-Driven Data Pipeline

A containerised event pipeline built for the failure cases: at-least-once delivery, bounded retries through a TTL delay queue, and a dead-letter queue so a malformed message cannot block the work queue. Two-layer idempotency uses atomic Redis SET NX on the fast path with a PostgreSQL UNIQUE constraint as the authoritative backstop. Deployed to Kubernetes with liveness and readiness probes, instrumented with Prometheus queue-depth and dead-letter metrics.

Server Operations

Host Provisioning & Model Serving Ops

A service that provisions and hardens its own host with Ansible roles: user and SSH key-only policy, ufw deny-by-default firewall, logrotate, and systemd units running as a dedicated service user.
